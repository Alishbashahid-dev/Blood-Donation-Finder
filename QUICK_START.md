# ⚡ Quick Start - Blood Donation Finder

Get started in 2 minutes! 🚀

---

## **Option 1: Download & Open (EASIEST)**

1. Download `blood_donation_finder.html` or `index.html`
2. Double-click the file
3. Done! ✅ (Opens in your browser automatically)

---

## **Option 2: GitHub Clone**

```bash
git clone https://github.com/YOUR_USERNAME/blood-donation-finder.git
cd blood-donation-finder
# Open index.html in browser
```

---

## **Option 3: Live on GitHub Pages**

1. Go to repo Settings
2. Pages → Main branch → root folder
3. Wait 1-2 min
4. Your live link appears! 🌐

---

## **Using the App (30 seconds)**

### **As a Donor:**
1. Fill form (Name, Blood Type, Phone, City)
2. Click "Register Donor"
3. Your card appears! ✅

### **As a Seeker:**
1. Search by name (optional)
2. Filter by blood type
3. Filter by city
4. Click "📞 Contact" to get phone
5. Call to arrange donation!

---

## **Features:**

✅ Instant search (by name)
✅ Filter by blood type
✅ Filter by city
✅ Filter by urgency
✅ All data saved locally
✅ Works on mobile
✅ No internet needed (after first load)
