# 🩸 Blood Donation Finder

A web-based platform connecting blood donors with patients in Pakistan in minutes, not hours.

![License](https://img.shields.io/badge/License-MIT-blue)

## 🎯 Problem Statement

Every year, millions of Pakistanis need blood transfusions. When it's urgent, finding a willing donor becomes a race against time. Currently:

- ❌ No centralized donor database
- ❌ Manual phone calls waste critical minutes
- ❌ Patients don't know who can help
- ❌ Donors can't register their availability

---

## ✨ Solution

**Blood Donation Finder** bridges this gap by:
- Connecting donors and patients in **under 60 seconds**
- Real-time search by blood type and location
- Urgency flagging for life-or-death situations
- Direct contact for immediate coordination

---

## 🚀 Key Features

✅ **Instant Donor Search** - Filter by blood type in seconds
✅ **Location-Based Matching** - Find donors in your city
✅ **Urgency Flags** - Mark critical cases (⚠️ Critical vs ✅ Normal)
✅ **One-Click Registration** - Register as donor in 2 minutes
✅ **Direct Contact** - Phone numbers to reach donors immediately
✅ **Persistent Data** - Information saved locally (no server needed)
✅ **Mobile Responsive** - Works perfectly on all devices
✅ **Fast & Offline** - No internet required once loaded

## 📊 Blood Type Compatibility Guide

| Blood Type | Donor To | Recipient From |
|-----------|----------|----------------|
| **O+** | All | O+, A+, B+, AB+ |
| **O-** | All | All |
| **A+** | A+, AB+ | A+, O+ |
| **A-** | All | A-, A+, O-, O+ |
| **B+** | B+, AB+ | B+, O+ |
| **B-** | All | B-, B+, O-, O+ |
| **AB+** | AB+ | All |
| **AB-** | All | AB-, AB+, A-, A+, B-, B+, O-, O+ |

## 📥 How to Use

### **Option 1: Download & Open**
1. Download `blood_donation_finder.html`
2. Double-click to open in browser
3. Start using immediately ✅

### **Step-by-Step:**

**As a Donor:**
- Fill form (name, blood type, phone, city)
- Click "Register Donor"
- Your card appears in list

**As a Seeker:**
- Search by name / Filter by blood type / Filter by city
- Click "📞 Contact" to get phone number
- Call directly
