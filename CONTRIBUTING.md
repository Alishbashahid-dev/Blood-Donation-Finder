# 🤝 Contributing to Blood Donation Finder

First off, thanks for considering contributing to Blood Donation Finder! It's people like you that make this project such a great tool.

## Code of Conduct

This project is committed to providing a welcoming and inclusive environment for all contributors.

---

## How Can I Contribute?

### 🐛 Reporting Bugs

Before creating bug reports, check the issue list. When you create a bug report, include:

- **Title:** Clear, descriptive title
- **Description:** What you expected vs. what happened
- **Steps to Reproduce:** How to reproduce the issue
- **Screenshots:** If applicable
- **Browser/OS:** What you're using

### 💡 Suggesting Enhancements

Enhancement suggestions are tracked as GitHub issues. When creating one:

- Use a clear, descriptive title
- Provide a detailed description
- List some examples of similar features
- Explain why this would be useful

### 🔧 Code Contributions

1. **Fork the Repository**
   ```bash
   git clone https://github.com/Alishbashahid-dev/blood-donation-finder.git
   ```

2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```

3. **Make Your Changes**
   - Keep changes focused and atomic
   - Test your changes thoroughly
   - Maintain code style consistency

4. **Commit Your Changes**
   ```bash
   git commit -m "Add amazing feature"
   ```

5. **Push to Your Fork**
   ```bash
   git push origin feature/amazing-feature
   ```

6. **Open a Pull Request**
   - Describe what you changed and why
   - Reference any related issues

---

## Development Setup

1. Clone the repository
2. Open `blood_donation_finder.html` in your browser
3. Make changes in your code editor
4. Refresh browser to test

No build process needed! We keep it simple.

---

## Pull Request Guidelines

- Follow the existing code style
- Comment complex logic
- Keep PRs focused on one feature/fix
- Update README if needed
- Add screenshots if UI changes

---

## Code Style

We use simple, readable vanilla JavaScript:

```javascript
// Good ✅
function findDonors(bloodType) {
  return donors.filter(d => d.blood === bloodType);
}

// Avoid ❌
function fd(b) {
  return donors.filter(d => d.blood === b);
}
```
